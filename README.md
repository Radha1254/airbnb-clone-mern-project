# Airbnb Clone – MERN Stack Project (WanderLust)

## 📌 Overview

A full-stack Airbnb-inspired web application built using the MERN stack. The platform allows users to browse property listings, create new listings, and manage them through a secure backend system with database integration.

---

## 🚀 Features

* User authentication (login/register) *(if implemented)*
* Create, read, update, and delete property listings
* View detailed listing pages
* Image upload support *(if implemented)*
* Responsive UI for better user experience
* RESTful API integration between frontend and backend

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/airbnb-clone-mern-project.git
```

### 2. Backend setup

```
cd backend
npm install
npm start
```

### 3. Frontend setup

```
cd frontend
npm install
npm start
```

### 4. Environment Variables

Create a `.env` file in backend:

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLOUDINARY_NAME=your_cloud_name
CLOUDINARY_KEY=your_api_key
CLOUDINARY_SECRET=your_api_secret
```
